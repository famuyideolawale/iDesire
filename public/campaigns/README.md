# Campaign art

Created with the built-in image-generation tool for the approved homepage designs. These are promotional campaign images, not representations of individual in-stock products. Actual supplied product images remain on catalogue cards and detail pages.

- `idesire-fashion-hero.webp`: saturated burgundy studio fashion campaign; adult Black Nigerian model wearing embroidered burgundy lace and gele, positioned on the right, with clear left-side negative space for the live headline. No embedded UI or lettering.
- `kokies-gift-hero.webp`: olive studio still life with a chocolate gift box, ivory ribbon, ivory tumbler, olive notebook, brass pen, cream card and gift bag. No embedded UI or lettering.

Generated PNG originals are retained in `output/imagegen/`. WebP encoding preserves original pixel dimensions while reducing transfer sizes to approximately 180 KB each. The files contain no text overlays: all website text, navigation and controls are rendered in HTML.

## Final generation prompts

Both images were generated with the built-in image-generation tool, without image references, with an opaque background. No CLI/API fallback was used. The final project assets are `/public/campaigns/idesire-fashion-hero.webp` and `/public/campaigns/kokies-gift-hero.webp`.
